Scope
-----
This archive synchronizes the A3-GBox64/F32 production closure with the latest
precision-aware procedural compiler theory: ray-quantization bounds, operator
taxonomy, branch-margin certification, Bernstein root certificates, compact
root clusters, effective degeneracy, and transport-budget lowering.

Status note
-----------
Kernel cost and direct-coefficient figures are explicitly labelled as
collaborator-reported results. Root-certificate and transport-budget figures are
from local Python prototype studies and are presented with their limitations.
