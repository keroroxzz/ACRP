# 研究總結

## 一、研究動機

這項研究最初想回答的，不只是「如何更快 ray marching」，而是更根本的問題：

> 一個描述射線前進與首次事件距離的抽象函數，究竟在什麼條件下，能被實際幾何或體積介質實現？

傳統 rendering 通常從幾何或密度場出發，再設計求交或積分演算法；我們反過來從 **Travel Field** 出發，先研究事件距離函數本身的結構，再問它對應什麼幾何、表面或介質。

這個視角有三個核心動機：

1. 建立從抽象 Travel function 到可實現幾何／介質的表示理論。
2. 避免把 procedural field 一律當成只能固定步長採樣的黑盒函數。
3. 利用 cell 內解析結構，將 rendering 從 heuristic marching 改寫為：
   [
   \text{cell traversal}
   +
   \text{analytic integration/root inversion}.
   ]

最終目標不是單一 shader，而是一套可推廣到程序化表面、體積雲與 radiative transfer 的解析 traversal 理論。

---

# 二、整體研究路線

研究可分成四個連續階段。

## 1. Travel Field 的抽象理論

首先定義五維直線光線狀態空間：

[
\mathcal X=\mathbb R^3\times S^2.
]

其中狀態為：

[
x=(\mathbf p,\boldsymbol\omega),
]

直線半流為：

[
\Phi_t(\mathbf p,\boldsymbol\omega)
===================================

(\mathbf p+t\boldsymbol\omega,\boldsymbol\omega).
]

Travel Field 定義為某個首次事件時間：

[
T(x)
====

\inf{t\ge0:\Phi_t(x)\in E}.
]

核心一致性條件是 countdown law：

[
T(\Phi_sx)=T(x)-s,
\qquad
0\le s<T(x).
]

這給出 Travel Realizability 的基本半流結構。

接著研究 ordinary 3D surface realizability。一般五維事件集合不一定來自普通三維表面；要退化為普通 surface，零事件集合必須沿方向纖維飽和：

[
T^{-1}(0)=\Sigma\times S^2.
]

也就是命中事件只能由位置決定，而不能依賴入射方向。

---

## 2. Surface Travel：從 height field 到平滑 procedural surface

第一個具體模型是高度場：

[
\Sigma_h={(x,y,z):z=h(x,y)}.
]

射線：

[
\mathbf r(t)=\mathbf p+t\boldsymbol\omega
]

與表面的交點由 clearance：

[
C(t)
====

## z_0+\omega_z t

h(x_0+\omega_x t,y_0+\omega_y t)
]

的最小非負根決定：

[
T_h
===

\inf{t\ge0:C(t)=0}.
]

由此推導了：

* countdown consistency；
* transversal root 與 grazing root 分類；
* Travel 對起點與方向的微分；
* grazing singularity：
  [
  \mathbf n\cdot\boldsymbol\omega=0;
  ]
* Lipschitz directional lower bound；
* directional escape criterion。

之後將 procedural surface 分成 cellwise polynomial。

### Bilinear surface cell

Bilinear cell：

[
h(\xi,\eta)=a+b\xi+c\eta+d\xi\eta.
]

沿射線後，clearance 為二次多項式：

[
C(t)=At^2+Bt+C.
]

因此每個 cell 內可解析求出 exact first hit。

全域演算法為：

[
\boxed{
\text{2D DDA}
+
\text{quadratic exact intersection per cell}
}
]

而不是 cell 內 fixed-step marching。

實驗結果顯示：

* exact DDA 輪廓品質穩定；
* uniform marching 在遠方、silhouette 與邊角處容易鋸齒；
* exact traversal 的 visited-cell 數顯著低於 uniform samples；
* cell height-range rejection 能讓：
  [
  N_{\mathrm{quadratic}}
  \ll
  N_{\mathrm{visited}}.
  ]

### Cubic-fade smooth value noise

為改善 bilinear surface 只有 (C^0) 的問題，引入：

[
s(x)=3x^2-2x^3.
]

二維 smooth value noise 沿射線產生最高六次 clearance polynomial：

[
\deg C\le6.
]

因為一般 sextic 沒有根式解，改用：

* Bernstein basis；
* convex-hull rejection；
* de Casteljau subdivision；
* safeguarded refinement。

實驗證明：

* surface 法線在 cell boundary 上明顯平滑；
* Bernstein rejection 有效；
* root refinement 只發生在少量候選區間；
* 誤差集中在 silhouette、grazing 與 visibility branch switching 附近。

同時也得到一個重要理論區分：

* regular root：
  [
  C(T)=0,\qquad C'(T)\neq0;
  ]
* singular／grazing root：
  [
  C(T)=0,\qquad C'(T)=0.
  ]

對 regular hit，Travel 由 implicit function theorem 保證局部光滑；grazing states 通常形成五維光線空間中的低一維奇異集合。

---

## 3. Volume Travel：從幾何距離推廣到光學深度

體積雲沒有唯一表面，因此核心量從 first surface hit 改為 accumulated optical depth：

[
A_x(t)
======

\int_0^t
\sigma_t(\mathbf p+s\boldsymbol\omega),ds.
]

給定指數分布光學深度：

[
\xi=-\ln(1-U),
]

free path 定義為 generalized inverse：

[
T_\xi(x)
========

\inf{t\ge0:A_x(t)\ge\xi}.
]

累積光學厚度滿足 cocycle：

[
A_x(s+t)
========

A_x(s)+A_{\Phi_sx}(t).
]

因此剩餘 optical-depth budget 具有 countdown law：

[
T_{\xi-A_x(s)}(\Phi_sx)
=======================

T_\xi(x)-s.
]

這將 surface Travel 與 volume Travel 統一到一個擴增狀態空間：

[
\widetilde{\mathcal X}
======================

\mathbb R^3\times S^2\times[0,\infty).
]

---

## 4. Analytic Procedural Participating Media

第一個體積模型是 3D trilinear density cell。

Trilinear density 沿射線為三次：

[
\rho(t)=c_0+c_1t+c_2t^2+c_3t^3.
]

因此 optical depth 為四次：

[
A(t)
====

\sigma_t
\left(
c_0t+\frac{c_1}{2}t^2+
\frac{c_2}{3}t^3+
\frac{c_3}{4}t^4
\right).
]

全域 free-path sampler：

1. 使用 3D DDA 穿越 voxel。
2. 空 cell 直接跳過。
3. 非空 cell 一次解析積分整段 optical depth。
4. 若 cell optical depth 小於剩餘 budget，整格 consume。
5. 只有包含事件的最後 cell 需要 inversion。

因此：

[
\boxed{
\text{3D DDA}
+
\text{exact cell optical-depth accumulation}
+
\text{one terminal inversion}
}
]

並且每條射線：

[
N_{\mathrm{inversion\ calls}}\le1.
]

實驗顯示：

[
N_{\mathrm{inversion}}
\ll
N_{\mathrm{integrated}}
\le
N_{\mathrm{visited}}
\ll
N_{\mathrm{uniform}}.
]

同時 analytic transmittance 與 fine-step uniform integration 高度一致。

# 三、單次散射雲渲染成果

在解析 camera free path 的基礎上，又加入了解析 sun transmittance：

[
T_{\mathrm{sun}}
================

\exp\left(
-\int_0^{t_{\mathrm{exit}}}
\sigma_t(\mathbf x+s\boldsymbol\omega_{\mathrm{sun}}),ds
\right).
]

相機射線與太陽陰影射線都使用：

[
\text{3D DDA}
+
\text{analytic cell integration}.
]

單次散射 estimator 為：

[
L
=

\omega_0,
p_{\mathrm{HG}}(\cos\theta),
T_{\mathrm{sun}},
L_{\mathrm{sun}}.
]

其中相機方向的：

[
T_{\mathrm{camera}}\sigma_t
]

已包含在 free-path sampling PDF 中，因此事件權重只保留 scattering albedo、phase、sun transmittance 與 sun radiance。

最終 shader 已產生合理的：

* 雲體輪廓；
* 朝陽亮面；
* 雲內 self-shadowing；
* 薄邊亮化；
* 高密度核心暗化；
* HG forward scattering；
* 無 fixed-step banding 的 shadow structure。

你提供的 debug 圖也驗證：

* camera visited cells 與幾何路徑一致；
* integrated cells 受 density support 控制；
* sun traversal 成為主要額外成本；
* sun optical depth 與最終暗部高度對應；
* collision distance 呈現合理的隨機 free-path distribution。

# 四、目前最重要的理論結果

## 1. Travel Realizability

合法 Travel Field 的核心是半流倒數一致性：

[
T(\Phi_sx)=T(x)-s.
]

普通表面實現還需要方向纖維飽和：

[
T^{-1}(0)=\Sigma\times S^2.
]

---

## 2. Height-field Travel equation

在 regular hit 區域：

[
\nabla_{\mathbf p}T
===================

-\frac{\mathbf n}
{\mathbf n\cdot\boldsymbol\omega},
]

且：

[
\boldsymbol\omega\cdot\nabla_{\mathbf p}T=-1.
]

grazing singularity 由：

[
\mathbf n\cdot\boldsymbol\omega=0
]

控制。

---

## 3. Cellwise Polynomial Travel

若 cell 內 procedural field 沿射線為 degree (d) 多項式，則 surface intersection 轉為 degree (d) root problem。

* bilinear surface：
  [
  d=2;
  ]
* cubic-fade 2D value noise：
  [
  d\le6.
  ]

沒有根式公式不代表只能 marching；仍可做 certified or conservative root isolation。

---

## 4. Optical-Depth Realizability

若 (A(x,t)) 滿足：

* (A(x,0)=0)；
* 非負單調；
* cocycle；
* 對 (t) 局部絕對連續；

則存在消光場：

[
\sigma(x)\ge0
]

使：

[
A(x,t)
======

\int_0^t
\sigma(\Phi_sx),ds.
]

---

## 5. Monotone Optical-Depth Inversion

free path 是單調 optical-depth clock 的左廣義反函數：

[
T_\xi
=====

\inf{t:A(t)\ge\xi}.
]

即使存在 zero-density plateau，first-event semantics 仍唯一。

最關鍵的簡化是：

[
A'(t)=\sigma_t(t)\ge0.
]

因此高次 optical-depth polynomial 不需要一般多根 isolation，只需 monotone inversion。

---

## 6. Cellwise Optical-Depth Travel Theorem

若 cell 內 density 沿射線為 degree (d)，則 optical depth 為 degree (d+1)。

* trilinear density：
  [
  d=3,\qquad \deg A=4;
  ]
* cubic-fade 3D value noise：
  [
  d\le9,\qquad \deg A\le10.
  ]

只要 density 非負，cell optical depth 單調，因此可整格 consume，並在最後 cell 進行 safeguarded inversion。

---

# 五、目前成果的準確定位

目前研究已完成的不是「所有 procedural media 的通用 closed-form renderer」，而是建立了以下可靠結果：

### 已經完成

* Travel Field 的半流理論骨架；
* ordinary surface realizability 條件；
* height-field Travel 推導；
* bilinear exact surface traversal；
* smooth surface Bernstein prototype；
* optical-depth cocycle 與 generalized inverse 理論；
* trilinear analytic volume traversal；
* camera free-path sampling；
* analytic sun transmittance；
* Henyey–Greenstein single scattering；
* 多個 Shadertoy 原型與定性驗證；
* LaTeX 論文初稿。

### 目前仍屬 practical，而非完全 certified

* smooth surface 的 tangent fallback；
* GPU 浮點 Bernstein solver；
* fixed-depth subdivision；
* cubic-fade degree-10 medium 的 safeguarded Newton；
* 尚未有完整 CPU high-precision reference 與統計 benchmark。

因此論文中應區分：

[
\text{mathematically exact cell integral}
]

與：

[
\text{finite-precision practical inversion}.
]

## 4. 多尺度雲與 fBm

真正雲層通常不是單 octave lattice field。

下一步 representation 問題是：

[
\rho(\mathbf x)
===============

\sum_{\ell=0}^{L-1}
a_\ell
\rho_\ell(2^\ell\mathbf x).
]

多 octave 疊加會讓單 cell polynomial degree 或 cell partition 急速增長。

可研究：

* octave-aligned hierarchical cells；
* per-octave analytic integration；
* lower／upper optical-depth bounds；
* coarse-to-fine traversal；
* residual density representation；
* adaptive inclusion of high-frequency detail；
* analytic base + stochastic residual tracking。

最可能的實用架構不是將所有 octave 展開成單一巨大多項式，而是：

[
\boxed{
\text{analytic low-frequency backbone}
+
\text{bounded high-frequency residual}
}
]

---

## 5. 與 delta／ratio tracking 結合

目前方法對 cellwise polynomial density 很有效，但對任意 black-box heterogeneous medium 不一定適合。

一條更廣泛的路線是 hybrid：

* low-frequency procedural component：解析積分；
* residual component：delta tracking 或 residual ratio tracking；
* analytic optical depth 作 control variate 或 baseline；
* stochastic estimator 只處理小 residual。

這可能比純 analytic 或純 stochastic 都更實用。

---

## 6. 多重散射

目前 renderer 只有 single scattering。

短期可以加入：

* ambient sky term；
* powder approximation；
* Beer-powder compensation；
* low-order multiple-scattering approximation。

更嚴格的方向則是：

* next-event estimation；

目前 primitive 已可自然作為每段介質 path 的 free-flight sampler。

## 7. Temporal accumulation 與 denoising

目前畫面主要受 Monte Carlo noise 限制。

下一步工程化可加入：

* blue-noise／Sobol sampling；

這不改變核心理論，但能讓 analytic traversal 的視覺品質更容易展示。

# 最精簡的一句總結

這項研究的核心成果是：

[
\boxed{
\text{將程序化渲染中的固定步長採樣，
改寫為半流 Travel 理論下的 cellwise event computation。}
}
]

對表面，事件是 clearance 的 first root。

對體積，事件是 monotone optical-depth clock 的 generalized inverse。

目前已經證明並實作：

[
\boxed{
\text{procedural field 並不必然只能被 marching；
只要 cell 內具有可積分或可隔離結構，
就能整格解析穿越，只在真正事件 cell 做反解。}
}
]

Claude 在本機的自我驗證閉環，最適合把這套目前以理論推導與 GPU prototype 為主的研究，推進成具有高精度 reference、反例搜尋、完整數據與可投稿可信度的正式工作。
